# Голос

Диктовка для Windows. Левый Ctrl + правый Alt - старт и стоп. Текст сам вставляется в активное окно.

Русский распознаёт GigaAM v3. Если выбрать English - перевод, можно говорить на любом языке, а текст будет на английском. Всё локально, без интернета.

## Скачать

Готовый архив с exe и моделями лежит в GitHub Releases.

Распакуй папку `Golos` целиком и запусти `Golos.exe`. Не вынимай exe из папки, рядом нужны `_internal` и `models`.

Первый запуск грузит модель пару секунд. Иконка появится в трее, возможно под стрелкой `^`.

## Как пользоваться

1. Поставь курсор в поле ввода.
2. Нажми левый Ctrl + правый Alt.
3. Скажи фразу.
4. Нажми ту же комбинацию ещё раз.

Текст появится в плашке и вставится туда, где был курсор.

## Трей

- Диктовка - включить или выключить.
- Запускать с Windows - автозагрузка.
- Пунктуация - выключить, если не нужны запятые и точки.
- Язык - русский или English - перевод.
- Открыть папку программы, о программе, выход.

В английском режиме Whisper переводит речь на английский. Это дольше, чем простое распознавание, обычно несколько секунд. Русский работает около 0.3-0.5 секунды.

## Если плохо слышно

Если видео или музыка играют через динамики, микрофон пишет и их. Поставь на паузу или надень наушники.

Если текст не вставляется в программу от администратора, запусти Голос тоже от администратора.

Настройки и лог: `%APPDATA%\Golos`.

## Сборка из исходников

Нужен Python 3.11.

```
python -m pip install -r requirements.txt
python fetch_models.py
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

Модели в репозиторий не кладу: GigaAM весит около 225 МБ, Whisper small еще больше. `fetch_models.py` скачает их в `models`, `build.ps1` соберет `dist\Golos`.

Иконка взята из Fluent UI System Icons, лицензия MIT лежит в `assets`. Список лицензий зависимостей: `THIRD_PARTY_NOTICES.md`.
