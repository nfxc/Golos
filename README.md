# Голос

Диктовка для Windows. Делал под себя, выложил на случай, если пригодится еще кому-то.

Левый Ctrl + правый Alt запускает запись, еще одно нажатие останавливает. Распознанный текст вставляется в окно, где стоял курсор.

Интернет не нужен. Русский распознает GigaAM v3, для английского стоит Whisper с переводом. В режиме English можно говорить на любом языке, на выходе будет английский.

## Установка

Скачай `Golos-win64.zip` из Releases и распакуй. Запускать `Golos.exe` нужно из папки, рядом должны лежать `_internal` и `models`.

Первый запуск занимает несколько секунд, пока загружается модель. Иконка будет в трее, возможно под стрелкой `^`.

## Трей

- Диктовка - включить или выключить.
- Запускать с Windows - автозагрузка.
- Пунктуация - если не нужны запятые и точки, можно выключить.
- Язык - русский или English с переводом.
- Открыть папку программы, о программе, выход.

Настройки сохраняются в `%APPDATA%\Golos`.

## Мелочи

Микрофон пишет все, что слышит, включая видео и музыку из колонок. С наушниками проще.

Если программа, куда нужно вставить текст, запущена от администратора, Голос тоже придется запустить от администратора.

## Сборка

Нужен Python 3.11.

```
python -m pip install -r requirements.txt
python fetch_models.py
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

Модели в репозиторий не кладу, они весят больше 600 МБ. `fetch_models.py` скачает их в `models`, `build.ps1` соберет `dist\Golos`.

Иконка из Fluent UI System Icons, лицензия MIT в `assets`. Лицензии зависимостей в `THIRD_PARTY_NOTICES.md`.
